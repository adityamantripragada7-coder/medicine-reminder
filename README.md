# Medicine Reminder App

This project is being built in phases as a full-stack college project.

## Structure

- `frontend/`: React and Vite user interface.
- `backend/`: Node.js, Express, and MongoDB API.

## Phase 1

### Install frontend dependencies

```powershell
cd C:\Users\adity\medicine-reminder\frontend
npm install
```

### Install backend dependencies

```powershell
cd C:\Users\adity\medicine-reminder\backend
npm install
```

### Start the frontend

```powershell
npm run dev
```

### Start the backend

```powershell
npm run dev
```
